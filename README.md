About FED-OS
FED-OS is an open-source ecosystem for browser-native AI tools, cross-platform publishing, universal web-app distribution, and creator-focused infrastructure. The project explores software that is accessible, portable, community-funded, and capable of working locally or offline wherever possible.

Mission
Browser-native AI: Build useful AI tools that run in the browser and can work offline.
Cross-platform publishing: Write once and distribute to multiple platforms.
Universal distribution: Make web applications easier to package, wrap, and ship everywhere.
Creator infrastructure: Provide open-source building blocks for independent creators and communities.
Privacy-conscious software: Keep projects free, MIT licensed, and free from in-app telemetry.
